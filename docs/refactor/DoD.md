# RAnki 重构验收清单 (Definition of Done / DoD)

### A. 时延指标
- [ ] 测试集：10 张卡，每张含 3~5 个复合公式（多层分式、极限、定积分、矩阵、方程组），每张翻 20 次（题→答案→下一题），共 ≥ 200 次采样。
- [ ] 自动埋点：`latency.csv` 给出 T_render、T_paint，P50/P95 均有记录。**T_render + T_paint P95 ≤ 100ms**。
- [ ] 冷启动后的第一次翻卡单独记录（引擎首次初始化），要求 ≤ 500ms，不计入 P95。
- [ ] 对照旧版：同一批卡在旧版（MathJax）上测同样指标，写入对比表，作为改善幅度证据。
- [ ] 外部验证（抽样）：手机 240fps 慢动作拍摄，记录点击到墨水屏可读的总时长，仅作为 T_panel 参考，不作为通过条件。

### B. 排版覆盖
- [ ] 全量公式回归：卡片库内全部公式用 KaTeX throwOnError:true 批量渲染，失败数 = 0；确有无法支持的命令，必须在文档中逐条列出并给出 macros 映射或卡片改写建议。
- [ ] 四种定界符 `\( \)`、`\[ \]`、`$ $`、`$$ $$` 各至少 3 张卡，真机显示正确。
- [ ] 化学：`\ce{MnO4- > Cl2}`、`\ce{2H2 + O2 -> 2H2O}`、带状态与电荷的方程式各至少 1 条，真机显示正确，且不报未知宏错误。
- [ ] 美元符号误判：卡片中出现货币 `$5` 之类普通文本时，不应被当成公式（出现则记录为已知限制，说明规避写法）。
- [ ] 公式错误兜底：故意写一条错误 LaTeX，页面不崩溃，错误处以可读方式显示（throwOnError:false），后续卡片仍可正常翻。
- [ ] 图片/媒体：含相对路径图片的卡片仍能显示。

### C. 横屏与缩放
- [ ] 竖屏（1072 宽）与横屏（1448 宽）下，各用一组超长公式（长推导、分块矩阵、重要极限展开）验证。
- [ ] 缩放比例 r ≥ 0.6 时：公式完整可见，无横向滚动条，字体仍清晰可读（300PPI 下目视确认）。
- [ ] r < 0.6 的极端公式：固定 0.6 + 局部横向滚动兜底可用，且不造成整页布局崩坏。
- [ ] 缩放后外层高度正确：公式下方文字不与公式重叠，也没有大片空白。
- [ ] 横竖屏切换：切换后当前卡片重新排版正确，触摸（翻卡/评分按钮）命中区域正确。

### D. 稳定性与资源
- [ ] 连续翻阅 ≥ 100 张卡（含公式），全程每 10 张记录 /proc/<pid>/status 的 VmRSS，增长 ≤ 5MB 且无单调上升趋势；无崩溃、无白屏。
- [ ] 全程无外部网络请求（断网环境运行；若原先保留了 127.0.0.1 服务则确认已移除或不再被页面使用）。
- [ ] 离线资源总体积 ≤ 2MB（SIZE.md 逐文件列出），运行期间不新增缓存文件（对比运行前后 ranki 目录文件列表）。
- [ ] 所有 JS 产物通过 acorn ES5 门禁；Kindle 日志无 SyntaxError / ReferenceError。
- [ ] 刷新策略：连续翻 30 张卡的残影可接受，保留或复现原有的全刷去残影机制。

### E. 数据纯净性
- [ ] 复习前后对比 collection 文件，卡片字段（notes.flds）内容逐字节一致（复习产生的复习日志与调度字段变化属正常，字段文本不得变化）。
- [ ] 代码审查：全仓库搜索，确认没有任何代码把渲染结果写回数据库或字段。
- [ ] 回环验证：在桌面 Anki 编辑一张卡的一个符号 → 同步 → KPW3 上显示更新，全程无需运行任何转换脚本。

### F. 交付
- [ ] CI 一键构建通过（含 ES5 门禁、体积断言、公式回归）。
- [ ] README 写明部署与回滚（保留旧路径开关或旧版 KUAL 包）。
- [ ] docs/refactor/phase1~5.md 完整，含原始实测数据。
