# Statement of Intent: KPW3 主力专注刷卡 Anki 客户端

> **状态**: Confirmed (用户显式确认)
> **日期**: 2026-11-20
> **目标硬件**: Amazon Kindle Paperwhite 3 (Model DP75SDI, 6" 300 PPI Carta E-ink 1072×1448, Freescale i.MX6 SoloLite 单核 ARMv7 `armel` 1.0 GHz, 512 MB RAM, Kindle OS 5.14.3.0.1, Linux 3.0.35-lab126, GLIBC ≤ 2.20)

---

## 已确认需求意图

- **目标 (Outcome)**：在越狱的 Kindle Paperwhite 3 (DP75SDI) 上打造一款专注刷卡、发挥硬件极致性能、界面美观顺眼的主力 Anki 客户端；技术路线与语言完全不设限，以真机性能、排版质感与日用稳定性最优为唯一标准（不强绑 Rust 或任何单一方案）。
- **用户 (User)**：本人——在 6 寸 300 PPI 墨水屏上日常主力复习理科（高数 / 理综 Cloze + LaTeX 公式）卡片的学习者。
- **背景与痛点 (Why now)**：
  - 原版 RAnki 每次翻卡公式渲染耗时数百毫秒，无法忍受；
  - 上一任重写的版本界面排版难看、丢失原版 Anki 居中对齐且真机体验甚至不如原版 RAnki，未达到主力可用标准。
- **成功标准 (Success)**：
  1. **极致流畅**：彻底消除翻面与切卡的数百毫秒公式卡顿，整体交互干脆利落、无明显残影拖尾；
  2. **纸书级美观排版**：
     - 牌组页清爽克制（对齐官方 Anki / AnkiDroid 的极简观感）；
     - 刷卡页严格像官方 Anki 一样**居中对齐**；
     - 忠实优雅地呈现个人 STEM 制卡规范中的内容形态：Cloze 完形填空、`\(...\)` / `\[...\]` / `\ce{}` 化学式 / `\bbox` 重点框、`<ruby>` 注音（含注音包裹公式）、`<cite>` 证明块、`<font color="red">` 关键对比词（在黑白墨水屏上清晰区分），以及 `<b>`、`<u>`、`<hr>`、`<ul><li>` 等基础结构；
     - 字体采用西文 `Anthropic Sans` + 中文 `SonyReader Ming`，重新按 300 PPI 纸书观感精细校准字号并支持调节；
  3. **完整专注刷卡闭环**：
     - 官方 Anki 真实调度与集合兼容（原生跟随电脑端 SM-2 / FSRS 设置）；
     - 多级子牌组树；
     - 实时 `新 + 学 + 复` 队列计数与四档评分（重来 / 困难 / 良好 / 简单）精确下次间隔；
     - 机内 Wi-Fi 双向同步 AnkiWeb（含自定义同步服务器、顺畅弹出 Kindle 虚拟键盘登录、仅存 token 不存明文密码）；
     - 高频刷卡控制：**撤销上一步 (Undo)**、**搁置 (Bury)**、**暂停 (Suspend)**；
     - 长卡无残影翻页与手动 / 自动清残影；
  4. **专注特色功能**：
     - 仿 iPhone Duo 的**圆形离散步进 20 秒专注倒计时**（低刷墨水屏友好、小区域单向离散步进）；
     - 仅在正面看题思考时运行，翻开答案立刻停止 / 隐藏；
     - 超时采用温和视觉提示（不强行替用户翻面或判错），支持在设置中开关与自定义秒数（默认 20 秒）。
- **硬约束 (Constraint)**：
  - 严格适配 KPW3 物理与固件边界（1072×1448 Carta 墨水屏、单核 1.0 GHz `armel` 软浮点、512 MB RAM、Linux 3.0.35、GLIBC ≤ 2.20）；
  - 开发与测试期严守数据安全红线，绝不读写或破坏生产牌组库（`D:\anki_data\`），所有开发验证严格在隔离测试库进行，经确认后再切换至主力库。
- **明确不做 (Out of scope)**：
  - 不做卡片图片渲染与媒体下载 / 同步；
  - 不做图片遮挡；
  - 不做音频播放；
  - 不做机内制卡 / 编辑卡片；
  - 不做 FSRS / 牌组调度参数编辑页；
  - 不做花哨统计图表与其他非刷卡装饰功能。
